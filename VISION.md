## 🧠 How AI Assistant Makes Decisions

### 80/20 Rule Engine

**Input:** User's task list + goals + time availability

**Process:**

```
For each task:
  1. Calculate Impact Score (1-10)
     - Directly contributes to goal? +5
     - Quick win (2-min rule)? +3
     - Learning new skill? +2
     - Maintaining existing? +1

  2. Calculate Effort Score (1-10)
     - 2-min task? 1
     - 1-hour task? 5
     - Full-day task? 10

  3. Calculate Priority Score = Impact / Effort
     - High Impact / Low Effort = TOP PRIORITY
     - Low Impact / High Effort = SKIP

  4. Sort by Priority Score
  5. Top 20% = Today's Focus
  6. Bottom 80% = Defer or Skip
```

**Output:**

```
✅ Do: Learn React (Impact 8, Effort 4, Score 2.0)
✅ Do: Build Auth (Impact 7, Effort 5, Score 1.4)
⏸️ Skip: Advanced animations (Impact 2, Effort 8, Score 0.25)
⏸️ Skip: Refactor legacy code (Impact 1, Effort 7, Score 0.14)
```

### Learning Path Optimization

**Input:** User's current skill level + goal

**Process:**

```
1. Identify Skill Gaps
   - Goal requires: React, Node.js, PostgreSQL
   - User knows: Basic JavaScript
   - Gaps: React, Node.js, SQL

2. Optimize Learning Order
   - Prerequisite: SQL (for data)
   - Foundation: React (for UI)
   - Backend: Node.js (for API)
   - Integration: All together

3. Determine Method
   - Feynman: Explain what you learned
   - Spaced Repetition: Review at intervals
   - Active Recall: Quiz yourself
   - Project-based: Build real things

4. Suggest Next Action
   - "Learn SQL basics (2 hours, video course)"
   - "Build React Todo app (4 hours, hands-on)"
   - "Deploy to Vercel (1 hour, practice)"
```

### Time Allocation Logic

**Input:** Task complexity + user energy level

**Process:**

```
Energy Level (User self-reported):
- High energy: Deep work (2-4h blocks)
- Medium energy: Standard work (25-50min Pomodoros)
- Low energy: Quick tasks (2-min rule)

Task Complexity:
- Simple (familiar): 25min Pomodoro
- Medium (learning): 50min Pomodoro
- Complex (new): 2h Deep work block

Recommendation:
IF energy == HIGH AND task == complex:
  → Time Block: 2h
IF energy == MEDIUM AND task == medium:
  → Pomodoro: 50min
IF energy == LOW:
  → Quick Tasks batch
```

## 💡 Technical Implementation

### AI Architecture

**Phase 1 (Current): Rule-Based**

```typescript
// Simple heuristics
function prioritizeTasks(tasks, goals) {
  return tasks
    .map((task) => ({
      ...task,
      score: (task.impact * goal.relevance) / task.effort,
    }))
    .sort((a, b) => b.score - a.score)
    .slice(0, Math.ceil(tasks.length * 0.2));
}
```

**Phase 2 (Prompt-Based):**

```typescript
// User interaction
const suggestion = await askAI('Given my goal: X and tasks: Y, what should I prioritize today?');
```

**Phase 3 (AI-Powered):**

```typescript
// OpenAI/Anthropic integration
const analysis = await openai.chat.completions.create({
  model: 'gpt-4',
  messages: [{ role: 'system', content: 'You are a productivity coach...' }],
});
```

### Data Flow

```
User Input → Goal Setting → AI Analysis → Task Generation → User Execution → Progress Tracking → AI Adaptation → Task Update
```

### Database Schema

```sql
-- Vision Goals
CREATE TABLE vision_goals (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  title TEXT NOT NULL,
  description TEXT,
  target_date DATE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Milestones
CREATE TABLE milestones (
  id UUID PRIMARY KEY,
  vision_goal_id UUID REFERENCES vision_goals(id),
  title TEXT NOT NULL,
  target_date DATE,
  progress INTEGER DEFAULT 0,
  status TEXT DEFAULT 'pending'
);

-- Projects
CREATE TABLE projects (
  id UUID PRIMARY KEY,
  milestone_id UUID REFERENCES milestones(id),
  title TEXT NOT NULL,
  color TEXT,
  progress INTEGER DEFAULT 0
);

-- Tasks
CREATE TABLE tasks (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES projects(id),
  title TEXT NOT NULL,
  impact_score INTEGER,
  effort_score INTEGER,
  priority_score FLOAT,
  status TEXT DEFAULT 'pending',
  completed_at TIMESTAMPTZ
);
```
